# 📝 Advanced Productivity Tracker

A premium and feature-rich Productivity Tracker web application built using HTML5, CSS3, and Vanilla JavaScript.

🚀 **Live Link:** https://tinyurl.com/pro-daily-tracker

## 🎨 Features
- **Weekly Progress Dashboard:** Real-time visual bar chart tracking completed tasks day-wise.
- **Dynamic Date & Time Logging:** Auto-calculates dates for the week and timestamps each task upon creation.
- **Instant Search & Interactive Filtering:** Real-time search engine with status filters (All, Active, Completed).
- **Persistent Storage:** Integrated with `LocalStorage` to save active states and user preferences seamlessly.
- **Glassmorphism UI & Dark Mode:** Persistent theme toggle with smooth animated gradient backgrounds.
